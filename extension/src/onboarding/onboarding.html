01

Choose how recipients open it

The popup defaults to Agent-ready: any Agent or person can open the unguessable link directly. Choose Encrypted when host-blind storage matters and the recipient has vnsh.

Your text → Choose visibility → One workspace → Shareable link
02

Try it: Right-click Share

Select the text below, then right-click and choose "Share via vnsh".

const server = http.createServer((req, res) => { console.log(`${req.method} ${req.url}`); res.writeHead(200, { 'Content-Type': 'text/plain' }); res.end('Hello from vnsh!'); }); server.listen(3000);

Right-click shares are encrypted. Use the popup for an Agent-ready link.

03

AI Debug Bundle

One click packages your current page's debug context (screenshot + console errors + selected text) into a single link. Shortcuts are encrypted; the popup can create an Agent-ready version that any AI assistant can fetch.

Cmd + Shift + D Debug Bundle
Cmd + Shift + S Screenshot Share
04

You're all set!

Here's what you can do:

  • Right-click selected text → Share via vnsh
  • Right-click an image → Share image via vnsh
  • Right-click → AI Debug Bundle for full context
  • Right-click → Save to vnsh (local clipboard)
  • Click the extension icon for the popup panel
Know what you share: Agent-ready is frictionless plaintext. Encrypted is host-blind but requires vnsh on the receiving side.
